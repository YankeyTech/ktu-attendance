Class rolls

Add, replace or delete a class roll for any lecturer, so they do not have to. The lecturer sees it on their page straight away. Upload a CSV or Excel file with Index number and Name columns. Uploading again for the same lecturer, course, programme and level replaces that roll only. If the lecturer has no course yet, choose Add a new course in the Course list. Deleted rolls go to the Trash tab for 3 months.

Settings

Shared venues

Save a lecture room once and every lecturer and teaching assistant can pick it on their Home tab, marked with a star. Stand in the room and press My position.

Levels

These appear on the student and lecturer pages. Removing one only hides it from the lists. Old records keep it.

Programmes

Add a programme that is missing, or hide one the university no longer offers. Classes already created keep their programme.

Hidden items

Semester rollover

Archive every class of a term in one click. Archived classes are hidden from the lists and from analytics (unless you tick Include archived), and nothing is deleted. You can restore them from the All classes tab.

Backup

Download an Excel file with all classes, check-ins, class rolls, courses and staff. It holds student names and index numbers, so keep it private. Phone and location details are left out.

Trash

Anything a lecturer or you delete is kept here for 3 months: classes with their attendance, class rolls, courses, venues, single check-ins and lecturer accounts. Restore it if it was deleted by mistake, or delete it for good. After 3 months it is removed automatically.

Admin tools

Report for one lecturer

An Excel sheet of every class a lecturer ran in a date range, with the number of check-ins.

Tidy index numbers

Makes index numbers capital letters with no stray spaces, so the same student is never counted twice.

My screen

Settings for how this admin page behaves on this device.

Quick controls

Fast actions for all classes at once. Every action is written to the Activity log.

Defaults for new classes

The minutes and distance lecturers see when they open the start form. They can still change them, within your limits. 0 means the standard value.

Messages for people

A welcome line on every lecturer's Home tab, and a notice on the student check-in page. Leave empty to show nothing.

System health

Database size, counts, and anything that needs attention.

Downloads and backups

Excel files of the records you manage. Keep a copy somewhere safe.

Add many venues at once

One venue per line: Name, radius, latitude, longitude (radius is optional). Example: Block B Hall 2, 80, 6.0912, -0.2601

Pause all check-ins

Use this in an emergency or during maintenance. Every check-in is refused with your message until you resume. Lecturers see a banner too. Classes and data are not touched.

Permissions for many people

Tick the people, choose what to change, then apply. "No change" leaves that permission as it is.

Block many students

Paste index numbers, one per line or separated by commas. They cannot check in to any class until you unblock them.

Class limits for everyone

Set the longest class and the smallest and largest allowed distance. Use 0 for no limit. Lecturers cannot go past these, and the database enforces it.

Daily limits per lecturer

Stops one account starting too many classes. 0 means no limit.

Lecturers who have gone quiet

People with no class in the chosen number of days. You can remind them in one tap.

Empty classes clean-up

Classes older than a day with no check-ins, often started by mistake. Move them to the Trash in one tap.

Attendance export by dates

All check-ins for classes held between two dates, as one Excel file.

Rules for starting classes

Extra control over when and where lecturers may start a class. The database enforces these.

Lock a whole term

A locked class cannot be edited, deleted or have its check-ins changed by lecturers. Use it when results are final.

Accounts with an end date

Set the end date on a lecturer's profile (Lecturers tab). After it, they cannot start classes.

Email alerts for problem reports

When someone sends a problem report, an email goes to every admin account. This needs the notify-report function (see the install steps). Paste its web address and your secret text, switch on, and press Save, then Send test email.

Feature switches

Turn a feature off for every lecturer. It is enforced in the database too. You are never blocked yourself.

Lecturer activity

Classes and check-ins per lecturer, and when each was last seen on the site.

Current term

Lecturers see this academic year and semester already filled in when they start a class.

Blocked students and phones

A blocked index number or phone cannot check in to any class. Block someone from Student lookup, or add one here.

Schedule a pause (maintenance window)

Check-in stops by itself at the start time and comes back at the end time. Leave the start empty to begin now. The message above is shown to students.

Index numbers with more than one name

The same index number was saved with different names in different classes. Pick the right name to correct every record.

Housekeeping

Archive classes older than a number of months. They are hidden from the default lists but kept, and you can restore them.

System

The free Supabase plan includes 500 MB of database space. Download a backup from Settings and clear old terms with the semester rollover before it fills up.

Health check

Looks for common problems in the data and fixes them with one click. Anything removed goes to the Trash.
