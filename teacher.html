Class roll and reports

Upload a CSV or Excel list of a course's students, with Index number and Name columns. Choose the programme and level the list belongs to, so the same course can have a separate roll for each programme and level. Then the class page shows who is missing (only students of that class's programme and level), and the report shows each student's attendance rate. Uploading again for the same course, programme and level replaces that roll only. For the report, the level is optional.
